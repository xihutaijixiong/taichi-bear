Obsidian是当前世界最好的笔记工具之一，你是否认可？

Obsidian在当下，我认为是值得被认为是当前世界最好的笔记工具之一的，当然它也有自己的确定，当你折腾过头，安装插件过多，也会以后卡，会有插件冲突，但是只要你不过渡折腾，始终还是以专注输入，成长输出为主，使用起来还是非常舒服的。
May 6, 2026

随着AI的发展和大神Karpathy的热帖被关注，Obsidian引来了一个新的高光时刻，越来越多的人开始使用Obsidian。

回想4年前我刚开始用笔记工具还是印象笔记，然后到Typora，再到Notion，最后确定用Obsidian作为我的唯一笔记工具，我发现找到适合自己的工具是多么重要。

对于INTJ的我来说，由于对各种笔记主题有要求，一直在Notion和Obsidian之间徘徊和纠结，最终终于生命不息，折腾不止的想法，决定选择Obsidian。

在折腾了3年之后，已经折腾出来一个自己的人生管理系统，回顾3年陪着Obsidian一起成长，我想说，Obsidian是当前世界最好的笔记工具之一，不知道大家是否认可？

先来总结一下使用过Obsidian三年后，Obsidian给我感受最深的几大好处：

  1. 安全性：在当前市场上有不下几十种笔记，如：飞书、语雀、思源、Notion、印象等等，真正完全可以本地的笔记屈指可数，本地存储直接解决了你终生记录笔记会丢失的风险，且不用过多考虑通过技术手段去备份，对于非技术用户不要太友好，你只需要去记录即可。
  2. 个性化：对于Obsidian强大的社区生态文化，你可以在Obsidian上按照自己的想法，尽情的去折腾各种插件，去探索各种应用场景，就像装修房子一样，可以随时换装修风格，当然前提是要先以输入输出为先。强大的个性化定制，拉满了Obsidian的趣味性，怎能不被它吸引。
  3. 便捷好用：对于Obsidian不需要考虑是否有网络，网络速度如何，打开即用，随时记录和折腾。如果你懂一点或者愿意学习一点技术，可以通过CSS深度折腾装修，如果你只想输入和输出，可以选择最简单的主题，通过最简单的base库进行打标管理，然后专注你的写作输出即可，没有任何其他阻碍。

写了这么多，接下来给大家分享一下在安全好用的前提下，我在使用过程中，最有趣也最有价值的几个个性化折腾。

反复折腾的自动化工作流#

不管怎么折腾，一定还是要以成长和效率为先，不然obsidian的价值就浪费了，因此，经过这几年，我认为最好入门，最好用的功能折腾，就是去反复折腾你工作和学习要用到的场景，形成一个自动化的工作流。

通过QuickAdd+Templater这个简单的组合，就可以快速创建笔记，记录你日常经常要用到的场景，比如：

  • 管理选题
  • 管理健康
  • 管理周计划
  • 管理认知
  • 管理日报
  • 管理写作
  • 管理周报 以上各种场景，我已经折腾了不下30个场景，但是经过折腾后，你会发现越来越聚焦，越来越高频的几个会留下来，然后就会自然形成习惯，慢慢的生长成为你人生系统的一部分。这种折腾本身就是成长的一部分，非常值得。

如果希望有更直观的趋势图来进行指标监控，可以如下： 代码如下：

// 读取数据
let pages = dv.pages('"004存档/生活/健康"')
  .where(p => p.weight && p.last_update)
  .sort(p => p.last_update);

// 转换数据
let labels = pages.map(p => p.last_update.toFormat("yyyy-MM-dd"));
let data = pages.map(p => p.weight);

// 生成 chart 代码块
let chartCode = `
\`\`\`chart
type: line
labels: [${labels.join(",")}]
series:
  - title: Weight
    data: [${data.join(",")}]
\`\`\`
`;

// 输出
dv.paragraph(chartCode);

以上只要学习过一次，后续维护只需要改变几个变量即可。

总结#

Obsidian在当下，我认为是值得被认为是当前世界最好的笔记工具之一的，当然它也有自己的确定，当你折腾过头，安装插件过多，也会以后卡，会有插件冲突，但是只要你不过渡折腾，始终还是以专注输入，成长输出为主，使用起来还是非常舒服的。
