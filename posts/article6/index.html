过去使用的Obsidian Web Clipper 1.3版本，更多的是用于剪藏和阅读，但是随着1.5版本都已经出来了，增加了视频字幕同步的功能，让我直接和油管界面说再见了。

当每次访问油管希望可以将优质的视频的内容文本进行沉淀和review总结的时候，还需要去寻找各种技术手段来实现，这次直接通过Obsidian Web Clipper一键实现了。

1.5版本阅读器功能支持油管视频的字幕交互了，你可以随时看到视频进展，同时看到字幕对应的上下文，暂停后，可以直接进行阅读理解或者记录。

设置阅读模式#

要想可以非常方便的使用阅读模式来看油管，只要进行如下简单的设置： 选择阅读器即可。

大纲与字幕交互体验#

打开浏览器后，点击网址左边的Obsidian Web Clipper图标：

点击之后就会形成如下的阅读器模式：

  • 左边大纲：左边直接按照原生的内容底层标记，形成一个大纲，方便你眼看到全视频的内容框架；
  • 中间字幕交互体验：打开不同的功能有不同的体验
    • 固定播放器：可以固定播放器
    • 自动滚动：可以直接滚动到当前进度
    • 高亮当前行：当前进度行会显示红色标记线和文本高亮
    • 单击字幕：通过单击字幕，直接跳转到当前字幕进度

当前不足#

阅读器模式只能通过浏览器的方式进行，当保存内容到obsidian中的时候，可见就没有那么好的交互体验了。

建议解决方案

如果希望也可以实现在obsidian中可以进行交互体验，就需要在obsidian中通过AI添加一个skill，给每个时间添加链接，让视频阅读可以同步浏览进行。

如果还希望有对应的中文翻译，也可以通过AI添加一个skill来进行补充翻译。

通过实现以上功能，基本代表已经实现了很多app的功能，间接帮你节约了大几百的app会员费用。
