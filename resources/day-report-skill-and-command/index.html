Daily Report Skill v1.0 and Command

用AI来进行自动化日报总结
July 22, 2026

Daily Report Skill v1.0#

Purpose#

根据 AI Company OS 当天新增及修改的 Markdown 文件，自动生成当天工作日报，并保存到新的日报笔记。

日报不评价，不夸奖，不推测，只基于当天实际内容进行总结。

Input#

AI Company OS 路径：

{{VaultPath}}

日报日期：

{{Today}}

输出目录：

02_Thinking/Daily Notes/

Scope#

仅分析：

今天新增的 Markdown 文件

+

今天修改过的 Markdown 文件

忽略：

.obsidian

Attachments

图片

PDF

Canvas

Templates

Archive

Trash

非 Markdown 文件

如同一文件今天修改多次，仅统计一次。

Workflow#

开始

↓

扫描今天新增文件

↓

扫描今天修改文件

↓

去重

↓

读取正文

↓

提取今日工作

↓

提取成果

↓

提取思考

↓

分析内容机会

↓

生成下一步建议

↓

生成日报 Markdown

↓

创建新笔记

↓

结束

Report Rules#

日报必须完全依据今天扫描到的内容。

禁止：

虚构

脑补

推测未来计划

评价工作好坏

夸奖

鸡汤

如果某部分没有内容，应输出：

今天暂无明显内容。

而不是自行补充。

Report Structure#

生成如下 Markdown：

# Daily Report - {{Today}}

---

## 一、今日工作总结

（200~400 字）

要求：

总结今天真正推进了哪些工作。

不要按照文件名罗列。

如果多个文件属于同一个主题，应进行合并总结。

---

## 二、今日主要成果

列出 3~5 项成果。

每项包括：

### 成果一

做了什么

为什么重要

对 AI Company OS 的推进作用

---

### 成果二

...

---

## 三、今日思考

根据所有笔记提炼今天形成的新原则。

相同思想进行合并。

例如：

- 工作流进一步简化
- Metadata 自动化原则
- AI Company OS 架构调整
- Prompt 设计原则

不要重复。

---

## 四、IP 内容机会

分析今天内容适合继续输出：

### 微信公众号

标题：

核心内容：

---

### 视频

标题：

核心内容：

---

### PDF

标题：

核心内容：

---

### AI Company OS 文档

标题：

核心内容：

---

如果没有适合内容：

写：

今天暂无明显内容。

---

## 五、下一步建议

结合今天已经开始的工作及当前进展和未来可能得发展规划。

输出 3~5 条（可以是规划，但是不仅限规划）。

要求：

继续推进已有工作。

不要新增完全无关项目。

建议必须可以执行。

例如：

- 完成 Metadata Builder v1.1
- 整理 Workflow Skill 文档
- 优化日报 Prompt

Output Rules#

创建新的 Markdown：

02_Thinking/Daily Notes/

{{Today}} Daily Report.md

例如：

02_Thinking/Daily Notes/

2026-07-07 Daily Report.md

Output Format#

直接输出完整 Markdown。

禁止输出解释。

禁止输出分析过程。

禁止输出 Prompt。

只输出最终日报内容。

File Creation#

若文件不存在：

创建：

02_Thinking/Daily Notes/{{Today}} Daily Report.md

若已经存在：

覆盖原内容。

Completion Report#

日报生成完成后，再输出一个执行报告：

# Workflow Report

扫描文件：

新增：
XX

修改：
XX

实际分析：
XX

生成日报：
√

输出位置：

02_Thinking/Daily Notes/{{Today}} Daily Report.md

Daily Report Skill v1.0 Command#

执行 Skill：

Daily Report Skill v1.0

AI Company OS 路径：

/Users/用户名/Documents/AI Company OS

要求：

1. 扫描今天新增和修改的 Markdown 文件
2. 根据 Skill 规则生成日报
3. 创建（或覆盖）：
   02_Thinking/Daily Notes/{{Today}} Daily Report.md
4. 输出 Workflow Report
